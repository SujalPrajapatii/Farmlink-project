Schema Legend & Conventions

PK Primary Key (Unique Table ID)
FK Foreign Key (Relational Link)
UNIQUE Unique Constraint
NO Not Null (Mandatory)
YES Can be NULL (Optional)
Design Principles Applied:
  • 3NF Normalization: Zero redundant columns.
  • Prefixed Primary Keys: Easy recognition in MySQL Workbench.
  • Dedicated Payments: 1-to-1 relation with Orders.
